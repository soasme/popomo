
# **Popomo.video – SLC v0 PRD**

### **1. Vision**

**Popomo.video** lets anyone — from kids to creators — make playful puppet-style videos through simple, visual programming.  
You drag stickers onto a stage, add cues, and hit play. Everything moves, dances, and talks — just like a handmade puppet show.

The magic: you don’t need to learn animation.  
You only need to **drop cues, drag actions, and record.**

----------

### **2. Goal of the SLC**

Build the **simplest, most delightful version** that lets users:

1.  Add images (characters, props) to a stage.
    
2.  Make them move and react with cue-based scripts.
    
3.  Preview the motion.
    
4.  Record the final performance as a video.
    

Nothing more. Nothing less.

----------

### **3. Core Concept**

-   **Blockly-based programming** drives the behavior of objects.
    
-   **Konva canvas** serves as the live stage.
    
-   **Cues** are simple timeline markers — the rhythm of the show.
    
-   **Camera** defines what’s recorded, just like a real puppet stage.
    
-   **Auto-save** keeps everything — projects reload instantly after refresh.
    

No complex timelines. No layers. No keyframes.  
Just _stickers that move when you say so._

----------

### **4. User Flow**

#### **Step 1: Create a Scene**

-   User opens Popomo.video and sees a blank stage with a camera box.
    
-   They drag in PNG stickers or props from local files.
    
-   Each dropped image becomes an **object instance** on the stage.
    

#### **Step 2: Add Cues**

-   User presses **M** or clicks **+ Cue**.
    
-   A small **Cue diamond** appears on the timeline (e.g., “Cue Fluffy”).
    
-   Cues have cute, random names (Fluffy, Kiki, Max, Bubbles) — fun and non-technical.
    
-   Cues are draggable to change timing and renameable via double-click.
    

#### **Step 3: Animate Objects**

-   User double-clicks an object → its **Blockly panel** opens.
    
-   They add tiny motion scripts like:
    
    -   “On Start → Move To (100, 200)”
        
    -   “On Cue Fluffy → Jump Up”
        
    -   “Wait 1s → Rotate 15° → Wait 0.5s → Rotate -15°”
        
-   No variables, no loops, just sequential fun blocks.
    

#### **Step 4: Play or Record**

-   Press **Play** → objects move, camera pans, audio plays.  
    Everything runs by cue timing.
    
-   Press **Record** → the canvas runs the same playback while capturing camera viewport frames to MP4.
    
-   When done, a cute message appears — “🎬 That’s a wrap!”
    

#### **Step 5: Auto-Save**

-   Every action (adding cue, moving sticker, changing script) instantly updates the local project in `localStorage`.
    
-   On reload, Popomo.video restores the last session automatically.

### **6. Core Features**

#### **6.1 Cues**

-   Add cues with `+ Cue` button or “M” key.
    
-   Each cue has:
    
    -   Unique ID (internal)
        
    -   Cute name (display)
        
    -   Time (movable on timeline)
        
-   User can drag cues to reorder timing freely.
    
-   Cues visually mark **moments** to trigger animations.
    

#### **6.2 Objects**

-   Draggable PNGs dropped onto the stage.
    
-   Each has:
    
    -   A name (auto “Sprite 1”)
        
    -   A transform (x, y, scale, rotation)
        
    -   Scripts for motion and audio
        
-   Double-click opens Blockly panel to edit scripts.
    
-   During playback, all scripts execute relative to cue timings.
    

#### **6.3 Camera**

-   Always visible as a box on canvas.
    
-   Defines recorded area (aspect ratio fixed per project).
    
-   Camera itself is programmable like an object (e.g., “On Cue Fluffy → Follow Hero”).
    
-   Users see live preview of camera framing before recording.
    

#### **6.4 Playback**

-   Press Play → all scripts run in sync with timeline.
    
-   Cues trigger instantly at defined times.
    
-   Canvas updates in real time.
    

#### **6.5 Recording**

-   Press Record → runs the same animation, captures only the camera viewport.
    
-   Outputs MP4 video file.
    
-   Playful completion message (e.g., “🎉 You just made your own Popomo show!”).
    

#### **6.6 Persistence**

-   Every change (objects, cues, camera, scripts) stored automatically to `localStorage`.
    
-   Reload → same state instantly restored.
    
-   No manual saving required.

----------

### **8. Constraints**

-   Works entirely offline after load.
    
-   Project state limited to browser localStorage (no server yet).
    
-   Maximum of 30 objects and 20 cues per project for now.
    
-   Max recording length: 60 seconds per export (for performance).
    
-   Audio: single-track, triggered from camera or cue.
    
-   Supported formats: PNG for assets, MP4 for exports.
    

----------

### **9. What’s Not Included (Yet)**

-   Multi-scene editing
    
-   Audio waveform timeline
    
-   Asset library or AI asset generator
    
-   Tween curves or easing
    
-   Collaboration / cloud saving
    
-   Multi-track mixing
    

Those can be later additions once the SLC proves lovable and complete.

----------

### **10. Success Criteria**

Popomo.video v1 is **successful** if:

-   A new user can make and record a 10-second puppet video **within 5 minutes**.
    
-   The first “Play” moment sparks delight — movement feels alive.
    
-   Reloading browser restores the exact same project.
    
-   The exported video plays perfectly synced and smooth.
